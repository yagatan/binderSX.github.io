# yagatan — RP-биндер на AutoHotkey v2

Сайт проекта YAGATAN RP Binder: описание, демо сценариев в браузере и ссылки на GitHub.

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.

Адрес после публикации: https://yagatan.github.io/binderSX.github.io/

## Редактирование

Весь сайт находится в `index.html`: разметка, стили и JavaScript. Сборка и установка зависимостей не нужны. Шрифт Manrope загружается из Google Fonts, при недоступности используется Arial.

Демо работает только внутри страницы: оно не подключается к игре и не запускает AutoHotkey. Кнопка «Создать Issue» открывает создание публичного GitHub Issue, для отправки нужен вход в GitHub.

Фон — анимация на Canvas. Анимацию можно поставить на паузу кнопкой на странице; при включённой системной настройке `prefers-reduced-motion` она отключается автоматически.
