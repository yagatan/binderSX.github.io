# yagatan — портфолио создателя AHK-биндеров

Адаптивный сайт с почти чёрным фоном, крупной объёмной типографикой и анимированным цветочным полем на Canvas. Включает презентацию YAGATAN RP Binder, интерактивную браузерную демонстрацию сценариев, информацию об авторе и ссылки на GitHub.

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.

Адрес после успешной публикации: https://yagatan.github.io/binderSX.github.io/

## Редактирование

Весь сайт расположен в `index.html`: разметка, стили и JavaScript. Сборка и установка зависимостей не нужны. Шрифт Manrope загружается из Google Fonts, при недоступности используется Arial.

Демонстрация работает только внутри страницы. Она не подключается к игре и не запускает AutoHotkey. Контактная кнопка открывает создание публичного GitHub Issue; для отправки нужен вход в GitHub.

Поддерживается уменьшение анимации через системную настройку `prefers-reduced-motion`, а также ручная пауза. Цветочное поле использует кэшированные спрайты, ограничение частоты кадров и отключается в скрытой вкладке. Проверены мобильная компоновка, запуск и остановка демонстрации, смена сценария и окно информации о проекте.


Фон сохраняется за всеми разделами: частицы поднимаются при прокрутке, раздвигаются вокруг курсора и возвращаются с пружинным сглаживанием. Заголовок плавно наклоняется в 3D, а блоки проявляются по мере появления в экране. Кнопка вниз запускает согласованный переход; ручная прокрутка прерывает его. На сенсорных экранах нет отталкивания от касания. Проверены сила отталкивания и возврат, мобильная ширина, появление карточек и ручная пауза.
